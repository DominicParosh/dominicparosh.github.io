## The idea

Today, structured generation, agent-graph optimisation and prompt optimisation live in separate frameworks. weave treats them as three optimisation passes over one shared intermediate representation. The compiler analyses and optimises the program statically; the interpreter runs the plan against live models.

## Status

- Phase 0, done: parser → IR → interpreter
- Phase 1, done: type system and diagnostics
- Phase 2, in progress: structured generation
